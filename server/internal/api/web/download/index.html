Quick guide

Which file do I need?

  • Most players
    Windows or Linux companion It installs the addon and the data pack for you — no folder hunting.
    Recommended
  • Addon managers
    TradePost addon zip Install it through your addon manager, or unpack it into Interface/AddOns.
    No companion
  • Live prices
    The companion Required for live prices, login and watchlist sync, and item metadata. Without it the addon warns you and disables live-only options.
    Required

Setup

First run, three steps

Five minutes, most of it waiting for WoW to load.

  1. 01

    Download and extract

    Grab the Windows or Linux companion and unpack it wherever you keep your tools.

  2. 02

    Run setup

    Close WoW, run tradepost.exe or ./tradepost, then open http://127.0.0.1:8787/setup and pick the folder containing _forever_.

  3. 03

    Install in game

    Install the addon, start WoW, and open the auction house once. Restart the client once after the first install; later code updates usually need only /reload.

Good to know

Before you install

  • No account needed

    Browsing is open. A one-time website login code is optional and only used for watchlist sync.

  • Windows may warn

    The binary is unsigned. If SmartScreen appears, choose More info → Run anyway.

  • Linux, no root

    Nothing is installed system-wide. Run the binary as your normal user.

  • Local dashboard

    The companion dashboard is served locally at 127.0.0.1:8787.
