# TradePost_Data (generated)

This addon is generated by the `tradepost` companion. Do not edit it by hand.

It contains the central price snapshot for the player's market(s), loaded at
login/`/reload`. A placeholder will be added in phase 1 so the addon can be
packaged and tested before the companion exists.

The companion writes this folder atomically; the game only reads it at load
time. The live mailbox (`docs/protocol.md`) carries deltas between reloads.
