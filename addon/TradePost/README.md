# TradePost (addon)

Auction house prices and tooltips for **WoW Forever**, with market-aware
filters, history, a watchlist, and a text-only item card.

## Companion required for full functionality

TradePost uses a small local companion (Linux/Windows) to fetch crowd-sourced
prices, keep the live price ring fresh, sync the watchlist, issue web login
codes, and run the optional metadata backfill.

Download and run it from:

https://github.com/Babo96/tradepost

The companion installs the generated `TradePost_Data` addon, the ring/auth
slots, and a tiny `TradePost_Companion` status addon with an `online` flag and
the latest addon release (`addon_latest`/`addon_url`). The addon warns in chat
and Settings when a newer release is reported, or when its TOC `## Interface`
is older than the client. If the companion is not detected at login/reload,
the addon:

- prints a chat warning that not all functionality is available,
- disables the live ring, web login and metadata options in Settings,
- keeps local scans, the browser, the watchlist, the Auctionator bridge and
  tooltips from any installed central data pack working.

The configured market is only a fallback: the active character's region,
ruleset (PvE/PvP/RP/etc.) and faction choose the live market automatically.
Horde/Alliance and PvP/PvE alts are supported.

## Commands

```
/tradepost            open settings
/tradepost browse     open the item browser
/tradepost scan       scan the auction house
/tradepost login      request a website login code (companion)
/tradepost watch ...  local watchlist
/tradepost meta ...   metadata backfill (companion, admin)
/tradepost help
```

## Data addon

`TradePost_Data` is generated by the companion (all known markets). A static
data pack can also be downloaded from the server, but live updates require the
companion.

## Branding

The TradePost mark is an original asset, not a Blizzard texture. The vector
source and 512px export live in `assets/`; the game uses the 32×32
`Media/icon.tga` through the TOC `## IconTexture` and the minimap button.
